두 상품 이미지를 비교해 같은 상품인지 판정한다.

입력은 이미지 2장:
1) 첫 번째 이미지: 큐텐(일본) 상품 cover
2) 두 번째 이미지: 한국 쇼핑몰 상품 cover

판정 기준 (위로 갈수록 가중치 큼):
- 패키지/디자인이 동일한가 (브랜드 로고, 색상, 라벨 텍스트, 모양)
- 같은 라인업의 변종(향/맛/용량)일 수 있는가 (점수 약간 낮춤, 0.5~0.7)
- 다른 카테고리·다른 브랜드면 0에 가깝게

규칙:
- 0.0 ~ 1.0 사이 score (소수점 2자리)
  - 1.0 = 거의 확실히 같은 상품
  - 0.7~0.9 = 같은 라인업·변종
  - 0.4~0.6 = 같은 카테고리·유사 컨셉
  - 0.0~0.3 = 다른 상품
- note 는 한국어로 한 문장. 점수 사유. 30자 이내.
- JSON 한 줄만 응답. 다른 설명 X.

응답 형식:
{"score": 0.85, "note": "동일 브랜드 동일 패키지, 다른 향"}
