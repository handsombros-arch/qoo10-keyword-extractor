## 2. 구성

| 구성요소 | 위치/기술 | 비고 |
|---|---|---|
| 백엔드 | `backend/` FastAPI + SQLAlchemy(async) + Playwright | `start.pyw` 더블클릭 → `localhost:8000`. `--reload` 없음 → 코드 수정 후 수동 재시작 |
| 프론트 | `frontend/` React 18 + Vite + Tailwind | `npm run build` 후 백엔드가 정적 서빙 |
| DB | Supabase Postgres (`backend/.env` `DATABASE_URL`) | 윈도우 메인 PC · 노트북 · 맥북이 **같은 DB 공유** |
| 크롬 확장 | `qoo10-helper-extension/` | 네이버/쿠팡 수집 시 메인 Chrome 경유 (AKAMAI 우회) |
| 자동화 스크립트 | `automation/` | `trigger_daily_rd.py` = 맥북 일일 수집 진입점 |
| 맥북 24h 서버 | `automation/mac/` (setup.sh, launchd plist) | Intel MBP, macOS 12, Python 3.14. **키워드+낙찰가 수집만** 담당 (AI 불가) |

재시작(윈도우 PowerShell):
```powershell
Get-NetTCPConnection -LocalPort 8000 -State Listen | %{Stop-Process -Id $_.OwningProcess -Force}
# 이후 start.pyw 더블클릭
```

## 3. 절대 제약 (위반 금지)

1. **키워드 누적 데이터 삭제 금지.** 큐텐은 지난 일자 데이터를 다시 못 뽑는다. `keywords` / `volume_history` / `bid_history` 등 누적 테이블에 DROP·DELETE 동반 작업 금지. 마이그레이션은 ADD COLUMN만.
   - `backend/app/db/sqlite_repo.py` `save_keywords` 에 데이터 안전가드 있음 (`KEYWORD_SAVE_GUARD_RATIO`, 기본 0.5 — 신규 배치가 기존 대비 급감이면 삭제 스킵). 이 가드를 우회하거나 약화시키지 말 것.
   - 동기화/저장은 항상 union. 줄어들면 경고. 말없는 덮어쓰기 금지 (`feedback_no_silent_data_loss.md`).
2. **유료 LLM API 사용 금지** (Claude API, OpenAI API, VPS 모두 ❌). 로컬 ollama(메인 PC RTX 5080)만 허용. 번역은 Papago 웹 자동화, 환율은 er-api 무료. LLM 호출 캐시/감축 과제는 6/4 폐기(무거운 AI 자체가 비활성).
3. **UI 껍데기 금지.** 백엔드 없이 화면만 만들지 말 것. 기능은 끝까지 작동하게 (`feedback_no_ui_shells.md`).
4. 작업 변경 후 **항상 커밋** (`feedback_always_commit.md`). 한글 포함 `.ps1` 은 UTF-8 BOM 필수.
5. 화면 버그는 스크린샷/구체 케이스 확인 후 수정. 확인 전 "고쳤다" 금지.
