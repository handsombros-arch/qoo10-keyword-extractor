## 4. 결론 — RTX 5080 추천 모델

| 영역 | 현재 | 권장 | 이유 |
|---|---|---|---|
| 번역 (TRANSLATE_MODEL) | ollama:qwen2.5:7b | **ollama:qwen3:14b** | 가나 잔존 80% → 0%. 9.3GB 메모리 충분. |
| 카테고리 (CATEGORY_MODEL) | ollama:qwen2.5:14b | (유지) + 입력에 컨텍스트 추가 | 모델보다 입력 결함 |
| 브랜드 (BRAND_MODEL) | ollama:qwen2.5:14b | (유지) + whitelist 시드 보강 | 모델보다 데이터 결함 |
| set_count | ollama:qwen2.5:7b | (유지) | 정규식 1차 + LLM 폴백 — 7b 충분 |
| 비전 (VISION/IMAGE_MATCH) | ollama:minicpm-v:8b | (유지, 추후 qwen2.5-vl 시도) | 이미지 매칭 양극화는 모델보다 프롬프트 |

**핵심 결론**: **번역만 qwen3:14b 로 교체** 하면 가나 잔존 32.7%가 0% 가까이 떨어짐. 다른 영역은 모델 변경보다 데이터/프롬프트 보강이 ROI 높음.
