2026-06-03. 사장님: "앞으로 껍데기만 만드는 일은 없도록 해." (엘비텐 연관검색어 소스 10+개 중 5개만 백엔드 구현, 나머지는 UI 체크박스만 있고 enabled:false 방치된 것을 발견하고)

**Why:** 엘비텐의 "기능은 많은데 활용도 떨어짐"의 근본 원인 = UI/함수만 만들고 실제 흐름에 안 꽂은 미완성(미연결)이 누적된 것. 껍데기는 "있는 것처럼 보이지만 안 되는" 혼란만 가중. [[project_lv10_reset]] 의 핵심 진단.

**How to apply:**
- 새 기능은 **UI + 백엔드 + 실제 흐름 연결까지 완결**해서 내놓는다. 절반(UI만/함수만/disabled placeholder)으로 두지 않는다.
- 지금 당장 다 못 만들면 **아예 안 만든다**(빈 체크박스/disabled 버튼/빈 페이지 추가 금지). TODO는 코드가 아니라 계획/메모리에 둔다.
- 기존 껍데기를 발견하면 **(a) 끝까지 구현하거나 (b) 제거**한다. 방치 금지.
- 작업 보고 시 "구현됨"과 "연결됨(실제 흐름에서 작동)"을 구분해서 말한다.
