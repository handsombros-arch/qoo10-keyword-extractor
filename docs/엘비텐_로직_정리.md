## 0. 기본 설정 / 핵심 지표

- **기본 카테고리: 뷰티 / 식품**
- **핵심 지표**: 수요(검색수) · 한국 비중 · 경쟁강도 · **경매 낙찰가 / 구좌(광고 슬롯) 여부** ← 매우 중요
- 핵심 발상: "여기서 **노출을 잡을 수 있는가**(구좌)" 가 관건. 경쟁이 많아도/낙찰가가 없어도 **구좌만 비어 있으면 진입 가능**.

## 🔁 핵심 사이클 (이게 도는 본체)

### 1) 키워드 찾기 — "들어갈 자리" 발굴
프로그램 돌려서:
- 경쟁자 적고 수요 많은 곳, **한국 비중 높은 곳**
- **낙찰가 없는 곳** → 구좌가 남아 있으면 OK (광고로 노출 가능)
- **상품 1천 개 이상 많아도** → 구좌 있으면 OK
- 기존에 **없던 새 키워드** (급부상)

> 엘비텐: ✅ 발굴(다중소스 자동완성) + 검색수/경쟁강도/**낙찰가** 수집. 🟡 존/구좌 관점 선별 UI는 보강 필요.
> ※ 기존 "황금존(경쟁 낮음)" 외에 **"붐비지만 구좌 열림", "낙찰 없고 구좌 열림"** 도 타겟 → 낙찰가/구좌가 1급 신호.

**"좋은 키워드" 기준 (6/4 확정):**
- **메인**: 🟡 황금존 = 경쟁강도 낮음 (유지). *한국비율은 보류 — display만, 게이트 X.*
- **서브**: 구좌 열림 = **낙찰수 ≤ 3** (들어가면 바로 상위 노출) · 🆕 **NEW** = 전일/전주 대비 첫 등장
- **화면**: 키워드당 **1행(최신 스냅샷)** + 라벨(황금존/NEW/상승/구좌) + 시계열 펼침 → 날짜 중복 제거.

### 2) 한국 소싱처 마진 비교 — "남는가" 판단
- **네이버 · 쿠팡** vs **큐텐 판매 중 상품** 가격 비교
- 마진 괜찮으면 진입 결정
- **마진 계산기 필요**

> 엘비텐: ✅ 네이버 검색(배송비 포함)·쿠팡·큐텐 수집 + 마진 계산. 🔲 환율 실시간 연결·계산기 다듬기.

### 3) 상품 등록 — SEO (제목/태그)
- **연관검색어 찾기** (구글 · 야후 · 블로그 등) → **태그** 작성
- **상품명 = 상품명 + USP + 연관검색어** 조합

> 엘비텐: ✅ 연관검색어(구글 サジェスト·야후·큐텐 등) + 큐텐 제목/태그 생성. 🟡 USP 결합·블로그 소스는 보강.

### 4) 상품 등록 — 상세페이지
- 상품 이미지 뽑기 + **AI** + **피그마** → 상세페이지
- 상품 등록 완료

> 엘비텐: 🟡 누끼/이미지 일부. 🔗 AI 이미지·피그마는 외부. (등록 자체는 큐텐 콘솔)

### 5) 노출 — 광고 최적화 (스마트세일즈 CPS → 플러스전시 CPT → 파워랭크업)
- **스마트세일즈(CPS)** 로 노출 테스트 (기간 정해서)
  - **순위추적 걸어두고** → "스마트세일즈 몇 % 넣으면 순위 몇 위" 체크
  - 아예 미노출이면 테스트 불가 → **무조건 광고 걸어야** 함
- 순익 나는지 / 노출→전환 바로 일어나는지 테스트
- 노출 잡히고 전환 되면 → **CPS → CPT(플러스 전시)** 로 전환해 순익↑ (구좌 비면)
- 판매되는데 플러스전시 경쟁 심하면 → **파워 랭크업**으로 순위↑
  - 순위 추적 → 그대로면 파워랭크업 드롭, 스마트세일즈·플러스전시를 **다른 키워드로** 돌림

> 엘비텐: ✅ **순위추적(M10)** — 광고% ↔ 순위 피드백의 핵심 도구 (백엔드 작동, **UI 노출 필요**).
> 🔲 CPS/CPT/파워랭크업 광고 집행·관리는 큐텐 콘솔(수동). 엘비텐은 **순위 추적·광고효율 모니터링** 역할.

### 6) 배송
- 상품 주문 → 패킹 → **배대지 발송**

> 엘비텐: 🔗 외부(주문·배대지). 추적/연동은 추후.

### 7) CS
- 나중에 생각. **API로 연결**해 처리하면 좋겠음.

> 엘비텐: 🔲 미정 (향후 API 연동 희망).

## 🧩 부수 기능 (사이클 보조)

### A) 올리브영 트렌드
- 브랜드·상품명 추출 → **일본어로 번역** → 검색 → 소싱할 상품 있나 / 쓸 만한 연관검색어 있나
> 엘비텐: ✅ 올영 랭킹 크롤(브랜드·상품명·가격). 🔲 번역→큐텐 역검색 연결.

### B) 샵 벤치마킹
- **샵 URL** 넣으면 → 그 샵의 잘 팔리는 상품 / 브랜드 / 리뷰수 / 가격 / 배송비
> 엘비텐: ✅ 샵 벤치마크(M13). 리뷰수/배송비 보강 여지.

## 📌 이 리뉴얼로 바뀐 점 (이전 정리 대비)

1. **사이클이 "마진"에서 끝나지 않음** → **광고 노출 최적화(5단계) + 배송 + CS** 까지가 본체.
2. **경매 낙찰가 / 구좌 = 1급 핵심 지표.** 키워드 선별이 "경쟁 낮음"만이 아니라 **"노출 잡을 수 있나(구좌)"** 중심.
3. **순위추적이 핵심 도구로 승격** (5단계 광고%↔순위 피드백) → UI 노출 우선순위↑ (이전엔 "나중에").
4. 카테고리 기본 = **뷰티/식품**.
5. 외부 의존 명시: 큐텐 광고 콘솔(집행)·피그마(상세)·배대지(배송)·AI 이미지.
