## 1. 프로그램 목적 (← 검토/수정 대상)

> **엘비텐은 "큐텐 재팬에서 팔릴 한국 상품을, 마진까지 계산해 등록 후보로 뽑아주는 도구"다.**

매일:
1. **발굴** — 큐텐에서 잘 팔릴/뜨는 키워드를 **소실 없이 누적**
2. **선별** — 경쟁 낮고 수요 있는 "황금" 키워드를 골라냄
3. **소싱** — 그 키워드로 한국(네이버/쿠팡) 상품·가격·배송비를 찾음
4. **계산** — 환율·수수료·배송비·세트수까지 반영한 **마진**을 뽑음
5. **검토·등록** — 마진 나는 후보를 시트에 모아 사장님이 검토 → 큐텐 등록

**이 한 문장 밖의 기능은 정리 대상.** (예: 안 쓰는 분석 페이지, 죽은 코드)

### 보조 목적
- **한국 트렌드 선행 감지**: 큐텐 데이터는 반 발짝 늦으므로, 올리브영 등 한국 라이징 트렌드를 **동시에** 본다(올영·다이소는 큐텐 니즈와 동행).

## 2. 핵심 운영 철학 (이번 재정비 합의)

- **B 반자동**: 확실히 되는 것만 끝까지 자동화. 불안정한 AI 매칭은 사람이 수동으로. ("기능 많은데 활용 안 됨" → "되는 걸 끝까지 연결")
- **데이터 절대 보존**: 큐텐은 크롤 후 과거 일자 복구 불가 → 누적 키워드/낙찰/순위 데이터는 절대 삭제·덮어쓰기 금지.
- **껍데기 금지**: UI만 있고 백엔드 없는 기능, 함수만 있고 안 꽂힌 기능을 만들지 않는다. 있는 건 끝까지 작동·연결.
- **비용 0 우선**: 비싼 LLM API는 안 씀. 소액·실익 있는 외부(번역 Papago 등)는 별도 판단.
- **맥북 24h 서버(경로 C)**: 평소 맥북 단독으로 가볍게, GPU 무거운 작업만 메인 PC(RTX 5080) 위임.

## 3. 완결 루프 (B 반자동)

```
🌙 야간 자동 (가벼움 — 맥북 단독 목표)
  ① 발굴   큐텐 트렌드 키워드 수집·누적(소실 금지)
  ② 분류   AI 카테고리/브랜드 (캐시)
  ③ 필터   존(Zone) 라벨링 — 버리지 않고 딱지만
  ④ 환율   오늘 실시간 환율 확보
        ⇒ "오늘의 후보 키워드 시트" (마진계산 준비 완료)

☀️ 낮 수동 (사장님)
  ⑤ 소싱   후보 키워드로 한국 상품 검색 → 시트에 붙임 (배송비 포함)
  ⑥ 입력   가격/무게/세트수 (set_count 자동 보조)
  ⑦ 마진   실시간 환율+수수료+배송비로 자동 계산 → 체크 → 큐텐 export

📊 병행   올리브영 카테고리별 랭킹 일일 크롤 (한국 트렌드 선행)
```

## 4. 키워드 로직 (발굴 엔진)

### 소스 → 검증 → 분류
```
[발굴] 소스에서 후보 키워드 (= 실제 일본인이 쓰는 말)
   ├ 큐텐 자동완성/연관/광고연관
   ├ 야후재팬(웹/쇼핑) 자동완성/연관
   ├ 아마존JP 자동완성/연관
   ├ Google サジェスト (소비자 리서치 의도: ~とは/使い方/おすすめ)
   └ (커뮤니티 태그 @cosme/LIPS/아메블로 — 보류)
        ↓ (모든 후보)
[검증] 큐텐 M03 → 주간검색수 + 전체상품수 → 경쟁강도(상품수/검색수)
        ↓
[분류] 존 라벨 (버리지 않고 딱지만 → 데이터 보존 + 활용도↑)
```

### 존(Zone) 모델 — 직관적 분류
| | 상품수 ≤200 | 상품수 >200 |
|---|---|---|
| **검색수 ≥50** | 🟡 **황금존** (핵심 타겟) | 🔴 레드오션 |
| **검색수 <50** | ⚫ 데드존 | 🟤 포화 |
- + 🆕 **신규**(과거 없던 첫 등장) · 📈 **상승**(직전 대비 +20%↑)
- 경쟁강도 = 황금존 내 정렬용 보조 지표
- 임계값(50/200/+20%)은 설정에서 조정

### 낙찰가(경매)
- 키워드 수집 시 광고 경매 낙찰가(1~10위 + 낙찰수)도 **같이 수집**(기본 ON). 광고비 가늠용.

## 5. 상품 로직 (소싱 → 마진)

### 한국 상품 소싱
- **네이버**: 검색결과 `__NEXT_DATA__` 파싱 → 상품명/가격/**배송비**/샵/직링크 (크롬 확장이 AKAMAI 우회). API보다 배송비까지 확보.
- **쿠팡**: 보조 (확장 경유).
- 후보를 큐텐 상품과 매칭 (텍스트 유사도) → 사장님이 최종 선택(B 반자동).

### 마진 계산
```
단가 = 가격 ÷ set_count(세트수)        ← 묶음가의 가짜 마진 방지
마진 = 큐텐 판매가(엔) − [한국 원가(원)÷환율 + 큐텐 수수료 + 한국 배송비]
```
- **실시간 환율** 반영 (Dunamu). *(현재 마진계산이 9.5 고정 → 연결 필요)*
- 큐텐 수수료/메가와리 부담률, 무게 기반 배송비 등 (가격 최적화 영역, 추후)

### 등록 콘텐츠
- 큐텐 제목(JP)/태그/마케팅 문구 자동 생성. "찐 일본 검색어"를 제목·태그에 활용.

## 7. 알려진 데이터 특성 (오해 방지)
