# 큐텐 자동화 마스터 문서

## 1. 비즈니스 컨텍스트
[큐텐에서 라이징 하는 키워드, 매출 잘 나올 것으로 보인느 키워드를 추출하여, 해당 키워드로 팔리는 상품을 국내에서 C2C로 일본 큐텐에 발송하는 역직구 수출 비즈니스.]

## 2. 야간 자동화 목표
[매일 19시 → 익일 아침 검토 가능한 시트]

## 3. 7단계 프로세스 + 현재 진행도
각 단계별:
- 명세 (본인이 원하는 것)
- 현재 구현 상태 (✅/⏳/❌)
- 빠진 부분
- 다음 액션

## 4. 핵심 비즈니스 룰
- 매칭 기준 (상품명 + 이미지 동시)
- 세트 제안 룰 (2만원 이하)
- 무게 룰 (300g → 500g)
- 마진율 임계값
- 임계점 (검색량, 한국비율 등)

## 5. 안전 장치
- 비용 한도
- Fallback 전략
- 로깅

## 6. Phase 진행 순서
- Phase 1 (현재): 시운전 + 잔여 작업
- Phase 2: 옵션 가격 + 배송비
- Phase 3: 시트 UI 실시간
- Phase 4: OCR + SEO
